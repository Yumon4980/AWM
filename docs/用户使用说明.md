# AltTabReplacer 使用说明

一款替代 Windows 默认 `Alt+Tab` 的窗口切换器。后台常驻，按下 `Alt+Tab` 即弹出选择器，选中即切换。

---

## 快速开始

### 1. 获取 exe

从项目 `publish/` 目录获取已经编译好的可执行文件，或者自行编译：

```powershell
dotnet build -c Release
# 生成路径：src\AltTabReplacer.App\bin\Release\net8.0-windows\AltTabReplacer.exe
```

### 2. 启动程序

> 程序需要**管理员权限**，否则收不到部分前台窗口的按键（如任务管理器在前台时会漏）。

**方式 A：双击运行**
在资源管理器中找到 `AltTabReplacer.exe`，右键 → **以管理员身份运行**。

**方式 B：命令行启动**
```powershell
Start-Process .\AltTabReplacer.exe -Verb RunAs
```

**方式 C：开机自启（不弹 UAC 提示）**
1. 打开「任务计划程序」（Win+R → `taskschd.msc`）
2. 创建任务 → 触发器选「登录时」
3. 操作：启动 `AltTabReplacer.exe`
4. 勾选「使用最高权限运行」

启动后**不会弹出任何窗口**，程序已驻留在系统托盘/后台。

### 3. 开始使用

在任意位置按下 **`Alt + Tab`** 即可唤起选择器：
- 默认选中第 1 个窗口
- 系统自带的 `Alt+Tab` 切换器被取代，不再弹出

## 快捷键速查

### 主选择器（一级）

| 按键 | 作用 |
|---|---|
| `Alt + Tab` | 唤起选择器（首次按下） |
| 再按 `Alt + Tab` | 关闭选择器（等同 `Esc`） |
| `1` `2` `3` `4` | 选中第 1–4 项 |
| `Q` `W` `E` `R` | 选中第 5–8 项 |
| `A` `S` `D` `F` | 选中第 9–12 项 |
| `Z` `X` `C` `V` | 选中第 13–16 项 |
| `Tab` / `↓` | 选中下一项（到底循环） |
| `Shift + Tab` / `↑` | 选中上一项 |
| `Enter` | 确认：程序直接切换，程序组进入二级 |
| `Esc` / `Backspace` | 逐级回退（二级 → 一级 → 关闭） |
| `/` | 进入搜索模式（跨组扁平搜索），`Esc` 退出 |
| 鼠标左键点击 | 切换到当前项 |
| 鼠标右键 | 弹出操作菜单（重命名/关闭/删除/解散等） |
| 鼠标拖动 | 拖到行中部=建组/并入；拖到行间=排序 |

### 二级（程序组内）

二级内同样支持 `1QWE / ASDF / ZXCV`、`Tab` 切换、`Enter` 确认、`Esc` 退回一级。

> 用 `Tab` 上下移动前要先**松开 `Alt`**。`Alt` 还按着时按 `Tab` 会被识别成热键，等同关闭选择器。

## 三种对象

| 对象 | 行为 |
|---|---|
| **程序** | 一个窗口。按下直接切换过去 |
| **程序组** | 容器。按下进入二级，里面放程序和程序组合 |
| **程序组合** | 一组程序（最多 4 个）。按下**同时打开全部**：已开则激活，未开则用记录的可执行路径启动 |

---

## 分组与组合操作

### 自动折叠
同一进程开了 ≥2 个窗口时，**自动折叠成一个程序组**，只占一个槽位。
- 阈值可在 `settings.json` 的 `Layout.AutoGroupThreshold` 中调整（设为 `99` 等于关闭此功能）

### 手动建组
- 把一行**拖到另一行的中部** → 建立程序组合（最多 4 个）
- 目标是程序组 → 把这一行**加入该组**
- 拖到行间 → 仅排序
- 按住 `Shift` 强制排序，按住 `Ctrl` 强制并入

### 新建程序组
- 点击左上角 **「+ 新建程序组」**，输入名字
- 再把程序/程序组合拖到该行中部即可加入

### 解散与删除
- **自动折叠的组**只剩 1 个成员时**自动解散**
- **手动建的组**即使为空也会保留
- 右键程序组 → **删除程序组**：只删容器，组内成员摊回一级
- 右键程序组合 → **解散程序组合**（一级二级都支持）
- 二级中把成员拖到顶部面包屑 → **移出该组**

> 程序组是严格两级结构：组里不能再嵌套程序组。

## 配置说明

所有配置文件位于 `%APPDATA%\AltTabReplacer\`（通常是 `C:\Users\<你>\AppData\Roaming\AltTabReplacer\`）。

| 文件 | 用途 |
|---|---|
| `settings.json` | 全局配置：热键、布局尺寸、主题 |
| `layout.json` | 槽位布局：顺序、分组（拖动后自动写入，支持热重载） |
| `rules.json` | 排除规则：哪些窗口不显示 |
| `logs\app-YYYYMMDD.log` | 每日滚动日志，调试用 |

### 默认 settings.json

```json
{
  "Hotkey": { "Modifiers": "Alt", "Key": "Tab" },
  "Layout": {
    "CellWidth": 256, "CellHeight": 144, "CellPadding": 8,
    "MaxColumns": 4, "AutoGroupThreshold": 2,
    "WidthRatio": 0.5, "HeightRatio": 0.55
  },
  "Theme": { "Accent": "#FF0078D4", "Background": "#CC202020", "CornerRadius": 8 },
  "Behavior": { "HideOnWindowChange": true, "IgnoreFullscreen": true, "PollIntervalMs": 1000 }
}
```

### 修改热键
编辑 `settings.json` 的 `Hotkey` 字段，例如改成 `F1`：
```json
{ "Hotkey": { "Modifiers": "", "Key": "F1" } }
```
或 `Ctrl + Alt + Tab`：
```json
{ "Hotkey": { "Modifiers": "Ctrl, Alt", "Key": "Tab" } }
```
保存后**重启程序**生效。

### 选择器窗口尺寸
- `WidthRatio` / `HeightRatio`：占主显示器工作区的比例（默认 0.5 / 0.55）
- 下限 640×420 DIP，屏幕比这还小时以屏幕为准
- 单位是 DIP，高 DPI 缩放下观感一致

### 规则示例
参考 `samples/rules.example.json`，格式大致：
```json
[
  { "Action": "Hide", "ProcessName": "explorer" },
  { "Action": "Hide", "Title": "Cortana" }
]
```

## 常见问题

**Q: 启动时弹出「请求的操作需要提升」错误？**
A: 必须用管理员身份启动。命令行加上 `-Verb RunAs`，或右键 exe → 以管理员身份运行。

**Q: 任务管理器在前台时按 Alt+Tab 没反应？**
A: 这是 Windows 的 UIPI 安全机制。AltTabReplacer 启动时已经申请管理员权限，如果还是不行，确认 exe 是用管理员身份启动的。

**Q: 如何开机自启又不弹 UAC？**
A: 通过「任务计划程序」创建登录时触发的任务，勾选「使用最高权限运行」。普通的「启动文件夹」和注册表 Run 项做不到免提示。

**Q: 某些窗口没有出现在选择器里？**
A: 当前版本默认过滤掉了 UWP / Store App（Cloaked 窗口）。需要在 `rules.json` 里调整排除规则。

**Q: 缩略图显示黑屏或「(no preview)」？**
A: 极少数使用 GPU 独占渲染的窗口无法被 `PrintWindow` 截取，已自动降级为占位图。

**Q: 如何彻底退出？**
A: 打开任务管理器（Ctrl+Shift+Esc）→ 找到 `AltTabReplacer.exe` → 结束任务。
或命令行：
```powershell
taskkill /im AltTabReplacer.exe /f
```

**Q: 按 1QWE 没反应？**
A: 确认鼠标焦点在选择器窗口内。点击选择器空白处后再按即可。

**Q: 修改 layout.json 后没生效？**
A: 程序支持热重载。如果不生效，确认 JSON 格式正确（没有逗号错误），可在日志文件 `%APPDATA%\AltTabReplacer\logs\` 中查看错误。

## 卸载

1. 结束进程：`taskkill /im AltTabReplacer.exe /f`
2. 删除 exe 文件
3.（可选）删除配置目录：`%APPDATA%\AltTabReplacer\`
4.（可选）删除「任务计划程序」中创建的自启任务
